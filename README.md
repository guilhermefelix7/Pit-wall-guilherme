# 🏎️ Pit Wall - Fórmula 1

## 📌 Sobre o projeto

O Pit Wall é um site desenvolvido com o objetivo de apresentar informações sobre a Fórmula 1, utilizando um visual inspirado nas equipes e competições do automobilismo.

O projeto possui um design moderno, com cores preto, vermelho e branco, buscando transmitir a identidade visual das corridas.

## 🎯 Objetivo

Criar uma página web sobre Fórmula 1, apresentando informações sobre pilotos, classificação e ingressos para o Grande Prêmio de São Paulo.

- **CSS3:** Estilização, cores, organização dos elementos e responsividade.
